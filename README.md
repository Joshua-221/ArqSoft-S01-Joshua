# GameStock - Catálogo de Videojuegos

Una aplicación web moderna desarrollada en **ASP.NET Core MVC** para gestionar y visualizar una colección personal de videojuegos, diseñada con una estética "Gamer" de alto impacto visual utilizando efectos LED/RGB y animaciones interactivas.

##  Descripción del Proyecto

Este proyecto es una plataforma interactiva para coleccionistas de videojuegos. El objetivo es proporcionar una interfaz dinámica donde el usuario pueda:
* **Visualizar** una colección completa de títulos con carátulas personalizadas.
* **Filtrar** juegos por género mediante una interfaz de botones neón.
* **Experiencia Inmersiva**: Navegación con fondos animados (lluvia de logos) y bordes de tarjetas con ciclos RGB completos.
* **Gestión**: CRUD completo para administrar los títulos de la colección.

##  Tecnologías Usadas

* **Backend:** ASP.NET Core MVC
* **Frontend:** HTML5, CSS3 (Animaciones personalizadas de espectro completo), Razor Pages
* **Framework Estilos:** Bootstrap 5.3 + Bootstrap Icons
* **Herramientas:** VS Code, Git, GitHub
* **Optimización:** Diseñado específicamente para un rendimiento fluido en entornos macOS (Apple Silicon).
